# Amazon-Inspired Personal Portfolio

A responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my profile, technical skills, projects, achievements, and contact information.

##  Features

- **Home:** Introduction and career interests.
- **About Me:** Educational background and professional profile.
- **Technical Skills:** Programming, data analysis, and visualization skills.
- **Achievements:** Research presentation, fellowship and bootcamp selections, and mentorship experiences.
- **Projects:** Highlights of my technical and analytics projects.
- **Contact:** Links to connect with me professionally.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Interactive UI:** Smooth scrolling and interactive navigation.

##  Technologies Used

- HTML5 — website structure
- CSS3 — styling, layout, and responsive design
- JavaScript — interactive functionality
- Git and GitHub — version control and project hosting
- GitHub Pages — website deployment
